# Source notes

This repository contains class code, coursework, and prior study solutions for file reading in java. It is one independent topic project from the recovered Data Structures materials.

## Working-copy changes

The recovered file-reading algorithms and worksheet output formats are retained. Working copies use the `data/fileio/` paths and accept an optional input filename. The unfinished `DidHeJustStealAnIdea.java` Lucas-reading starter is preserved in the archive; `LucasNumbers.java` is its completed counterpart. The extra `nums.txt` dataset is retained as another numeric input.

## Organization

Source and sample input bytes were copied from the previously verified working collection. Source files are now directly under `src/`. Each repository has its own source list, README, original snapshots, and a topic-specific runner assembled from the existing regression checks. No algorithm changes were made during this split.

Build output and compiled classes are excluded from the package. Original snapshots are not compiled, because they can contain unfinished code or duplicate class names.
